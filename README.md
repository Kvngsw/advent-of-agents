# Agent Governance & Execution Harness

A production-grade, low-RAM, secure execution and streaming harness for autonomous agent systems. The harness integrates pre-flight AST static analysis, cryptographic capability token signing, scale-to-zero Cloud Run micro-VM sandboxing, and real-time Gemini Live bidirectional multimodal streaming.
